# 🏅 Olympics Data Analysis

An end-to-end exploratory data analysis (EDA) project analyzing historical Olympic Games performance, athlete demographics, country medal tallies, and discipline evolution.

## 📊 Project Overview
This project dives into historical Olympic data to evaluate multi-decade trends across athlete participation, sports dominance, and national performance metrics.

### Key Insights & Features
- **Participation Trends:** Tracks athlete growth, gender distribution over time, and age/physical attribute metrics across different disciplines.
- **Medal Tallies:** Aggregates and ranks gold, silver, and bronze medal distributions across participating National Olympic Committees (NOCs).
- **Country & Sport Analysis:** Identifies sport dominance per region and evaluates performance stability across Summer/Winter games.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Plotly
- **Environment:** Jupyter Notebook
